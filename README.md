# 📹 VideoCall — Браузерные видеозвонки

Приложение для видеоконференций через браузер с анонимным доступом по 6-значному коду комнаты.

## Возможности

- ✅ Видеозвонки через браузер без установки ПО
- ✅ Анонимный доступ по 6-значному коду комнаты
- ✅ Поддержка 2-5 участников
- ✅ Текстовый чат в реальном времени
- ✅ Демонстрация экрана
- ✅ Управление камерой и микрофоном
- ✅ Выбор устройств (камера/микрофон)
- ✅ Адаптивный UI для мобильных и десктопных браузеров
- ✅ Автоматическое переподключение при разрыве соединения

## Технологии

- **Фронтенд**: Vanilla JavaScript (ES6-модули), WebRTC API
- **Signaling-сервер**: Node.js, Express, Socket.io
- **STUN-серверы**: Публичные Google STUN

## Быстрый старт

### Требования

- Node.js >= 16
- npm или yarn
- Современный браузер с поддержкой WebRTC (Chrome, Firefox, Safari, Edge)

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd browser-video-call
```

2. Установите зависимости сервера:
```bash
cd server
npm install
```

3. Установите зависимости клиента (опционально, для разработки):
```bash
cd ../client
npm install
```

### Запуск локально

1. Запустите сервер (в терминале 1):
```bash
cd server
npm start
```
Сервер запустится на `http://localhost:3001`

2. Запустите клиент (в терминале 2):
```bash
cd client
npx serve .
```
Клиент будет доступен на `http://localhost:3000`

3. Откройте `http://localhost:3000` в браузере

### Использование

1. **Создать комнату**: Нажмите "Создать комнату" → скопируйте код комнаты → отправьте собеседнику
2. **Войти в комнату**: Введите 6-значный код → нажмите "Войти в комнату"

## Конфигурация

### Переменные окружения сервера

Скопируйте `.env.example` в `.env` и настройте:

```env
PORT=3001
CLIENT_URL=http://localhost:3000
STUN_SERVERS=stun:stun.l.google.com:19302,stun:stun1.l.google.com:19302
```

### TURN-серверы (для production)

Для работы через симметричные NAT (~10-20% случаев) рекомендуется настроить TURN-сервер:

```env
TURN_SERVERS=turn:your-turn-server.com:3478
TURN_USERNAME=your-username
TURN_PASSWORD=your-password
```

## Тестирование

### Ручное тестирование

1. **1-on-1 звонок**: Откройте два браузера/вкладки → создайте комнату → войдите
2. **Групповой звонок**: 3-5 участников → проверьте все видеопотоки
3. **Демонстрация экрана**: Нажмите "Демонстрировать экран" → проверьте у других
4. **Чат**: Отправьте сообщения → проверьте доставку
5. **Переподключение**: Закройте вкладку → откройте заново → введите код
6. **Мобильные браузеры**: Проверьте на iOS Safari и Android Chrome

### Проверка ограничений

- **Максимум 5 участников**: Попытка входа 6-го должна показать ошибку
- **Генерация имён**: Вход без имени → должно сгенерировать "прилагательное существительное"

## Известные ограничения

- Максимум 5 участников (mesh-топология)
- Нет TURN-сервера по умолчанию (может не работать за некоторыми NAT)
- Нет записи звонков
- Нет регистрации пользователей
