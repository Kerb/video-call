## Purpose

Управление комнатами для видеозвонков: создание, генерация уникальных 6-значных кодов, вход по коду, восстановление сессии после разрыва соединения.

## ADDED Requirements

### Requirement: Генерация уникального кода комнаты
Система ДОЛЖНА генерировать уникальные 6-значные коды для комнат.

#### Scenario: Генерация кода при создании комнаты
- **WHEN** создаётся новая комната
- **THEN** система генерирует код из 6 символов (латинские буквы A-Z и цифры 0-9)

#### Scenario: Уникальность кода
- **WHEN** генерируется новый код
- **THEN** код ДОЛЖЕН быть уникальным среди всех активных комнат (не повторяться в течение минимум 24 часов)

### Requirement: Формат кода комнаты
Код комнаты ДОЛЖЕН соответствовать определённому формату.

#### Scenario: Валидный код
- **WHEN** код вводится пользователем
- **THEN** система принимает только коды из 6 символов, содержащих латинские буквы (A-Z, a-z) и цифры (0-9)

#### Scenario: Регистронезависимость
- **WHEN** пользователь вводит код в нижнем регистре (abc123)
- **THEN** система приводит код к верхнему регистру (ABC123) и находит комнату

### Requirement: Время жизни комнаты
Система ДОЛЖНА управлять временем жизни комнаты.

#### Scenario: Активная комната
- **WHEN** в комнате есть хотя бы один участник
- **THEN** комната остаётся активной и доступной для входа

#### Scenario: Очистка пустой комнаты
- **WHEN** все участники покинули комнату
- **THEN** комната остаётся активной в течение 60 минут для возможности возврата

#### Scenario: Удаление устаревшей комнаты
- **WHEN** комната пуста более 60 минут
- **THEN** система может удалить комнату и её код становится доступным для повторного использования

### Requirement: Информация о комнате
Система ДОЛЖНА хранить и предоставлять информацию о состоянии комнаты.

#### Scenario: Количество участников
- **WHEN** пользователь входит в комнату
- **THEN** система отображает текущее количество участников в комнате

#### Scenario: Список участников
- **WHEN** пользователь находится в комнате
- **THEN** система отображает список всех текущих участников (по идентификаторам сессии)

### Requirement: Восстановление сессии
Система ДОЛЖНА позволять пользователю восстановить соединение после разрыва.

#### Scenario: Повторный вход по тому же коду
- **WHEN** пользователь случайно потерял соединение (закрыл вкладку, пропал интернет)
- **THEN** пользователь может ввести тот же код комнаты и вернуться в звонок

#### Scenario: Сохранение идентичности при переподключении
- **WHEN** пользователь переподключается к комнате
- **THEN** остальные участники видят его как того же участника (с тем же именем/аватаром, если реализовано)
