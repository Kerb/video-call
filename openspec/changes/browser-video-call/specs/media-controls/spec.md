## Purpose

Управление медиа-устройствами пользователя: выбор камеры и микрофона, включение/выключение видео и аудио, демонстрация экрана, настройка устройств.

## ADDED Requirements

### Requirement: Запрос доступа к медиа-устройствам
Система ДОЛЖНА запрашивать разрешение на доступ к камере и микрофону.

#### Scenario: Первый запрос доступа
- **WHEN** пользователь входит в комнату впервые
- **THEN** браузер запрашивает разрешение на доступ к камере и микрофону

#### Scenario: Отказ в доступе
- **WHEN** пользователь отклоняет запрос доступа
- **THEN** система показывает сообщение "Доступ к камере/микрофону необходим для участия в звонке" и предлагает попробовать снова

### Requirement: Включение/выключение видео
Система ДОЛЖНА позволять пользователю управлять своей камерой.

#### Scenario: Выключение камеры
- **WHEN** пользователь нажимает кнопку "Выключить видео"
- **THEN** видеопоток пользователя прекращает отправляться, остальные участники видят заглушку (иконку или аватар)

#### Scenario: Включение камеры
- **WHEN** пользователь нажимает кнопку "Включить видео"
- **THEN** видеопоток пользователя возобновляется, остальные участники видят видео

### Requirement: Включение/выключение микрофона
Система ДОЛЖНА позволять пользователю управлять своим микрофоном.

#### Scenario: Выключение микрофона
- **WHEN** пользователь нажимает кнопку "Выключить звук"
- **THEN** аудиопоток пользователя прекращает отправляться, остальные участники не слышат его

#### Scenario: Включение микрофона
- **WHEN** пользователь нажимает кнопку "Включить звук"
- **THEN** аудиопоток пользователя возобновляется

### Requirement: Выбор устройства
Система ДОЛЖНА позволять пользователю выбирать камеру и микрофон из доступных устройств.

#### Scenario: Список доступных камер
- **WHEN** пользователь открывает настройки устройств
- **THEN** система отображает список всех доступных камер и позволяет выбрать одну

#### Scenario: Список доступных микрофонов
- **WHEN** пользователь открывает настройки устройств
- **THEN** система отображает список всех доступных микрофонов и позволяет выбрать один

#### Scenario: Переключение устройства во время звонка
- **WHEN** пользователь выбирает другое устройство во время звонка
- **THEN** система переключается на новое устройство без разрыва соединения

### Requirement: Демонстрация экрана
Система ДОЛЖНА позволять пользователю демонстрировать свой экран или окно приложения.

#### Scenario: Начало демонстрации
- **WHEN** пользователь нажимает кнопку "Демонстрировать экран"
- **THEN** браузер запрашивает выбор окна/вкладки/экрана для демонстрации

#### Scenario: Демонстрация участникам
- **WHEN** пользователь начал демонстрацию экрана
- **THEN** остальные участники видят транслируемый экран в реальном времени

#### Scenario: Завершение демонстрации
- **WHEN** пользователь нажимает кнопку "Остановить демонстрацию"
- **THEN** демонстрация прекращается, участники снова видят видеопоток пользователя

### Requirement: Индикация состояния медиа
Система ДОЛЖНА отображать текущее состояние медиа-устройств пользователя.

#### Scenario: Визуальная индикация
- **WHEN** видео или аудио выключено
- **THEN** соответствующая кнопка показывает состояние (перечёркнутая иконка, красный цвет)

#### Scenario: Индикация активного говорящего
- **WHEN** участник говорит (уровень аудиосигнала выше порога)
- **THEN** интерфейс показывает, кто из участников сейчас говорит (подсветка рамки)
