## Purpose

Обеспечивает базовую функциональность видеозвонков через браузер с поддержкой 2+ участников, используя WebRTC для передачи аудио и видео в реальном времени.

## ADDED Requirements

### Requirement: Пользователь может инициировать видеозволок
Система ДОЛЖНА позволять пользователю создать новую комнату для видеозвонка.

#### Scenario: Создание новой комнаты
- **WHEN** пользователь открывает приложение
- **THEN** система генерирует уникальный 6-значный код комнаты и отображает его пользователю

### Requirement: Пользователь может присоединиться к существующему звонку
Система ДОЛЖНА позволять пользователю войти в комнату по 6-значному коду.

#### Scenario: Успешный вход в комнату
- **WHEN** пользователь вводит корректный 6-значный код комнаты
- **THEN** система подключает пользователя к видеозвонку с остальными участниками

#### Scenario: Ошибка при неверном коде
- **WHEN** пользователь вводит код, не соответствующий формату (не 6 символов или недопустимые символы)
- **THEN** система показывает ошибку "Неверный формат кода. Код должен содержать 6 латинских букв или цифр"

#### Scenario: Комната не найдена
- **WHEN** пользователь вводит корректный код, но комната не существует
- **THEN** система показывает ошибку "Комната не найдена. Проверьте код или создайте новую комнату"

### Requirement: Поддержка множественных участников
Система ДОЛЖНА поддерживать видеозвонки с двумя и более участниками.

#### Scenario: Подключение второго участника
- **WHEN** первый участник уже в комнате
- **THEN** второй участник может присоединиться, и оба видят и слышат друг друга

#### Scenario: Подключение третьего и последующих участников
- **WHEN** в комнате уже есть 2+ участника
- **THEN** новый участник может присоединиться, и все участники видят видеопотоки друг друга

### Requirement: Передача видеопотока
Система ДОЛЖНА передавать видеопоток каждого участника остальным участникам.

#### Scenario: Отправка видео
- **WHEN** пользователь разрешил доступ к камере
- **THEN** видеопоток пользователя передаётся остальным участникам в реальном времени

#### Scenario: Получение видео от других
- **WHEN** в комнате есть другие участники с включённой камерой
- **THEN** пользователь видит видеопотоки всех остальных участников

### Requirement: Передача аудиопотока
Система ДОЛЖНА передавать аудиопоток каждого участника остальным участникам.

#### Scenario: Отправка аудио
- **WHEN** пользователь разрешил доступ к микрофону
- **THEN** аудиопоток пользователя передаётся остальным участникам с минимальной задержкой (<500мс)

#### Scenario: Получение аудио от других
- **WHEN** в комнате есть другие участники
- **THEN** пользователь слышит аудиопотоки всех остальных участников

### Requirement: Обработка разрыва соединения
Система ДОЛЖНА обеспечивать возможность переподключения при случайном разрыве соединения.

#### Scenario: Переподключение после разрыва
- **WHEN** соединение пользователя разорвалось (например, пропал интернет)
- **THEN** пользователь может повторно ввести код комнаты и вернуться в тот же звонок

#### Scenario: Сохранение комнаты при выходе одного участника
- **WHEN** один участник покинул комнату (закрыл вкладку)
- **THEN** комната остаётся активной для остальных участников
