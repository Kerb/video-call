## Purpose

Текстовый чат для обмена сообщениями между участниками видеозвонка в реальном времени.

## ADDED Requirements

### Requirement: Отправка сообщений
Система ДОЛЖНА позволять участникам отправлять текстовые сообщения.

#### Scenario: Отправка сообщения
- **WHEN** пользователь вводит текст в поле ввода и нажимает Enter или кнопку "Отправить"
- **THEN** сообщение отправляется всем участникам комнаты и отображается в чате

#### Scenario: Пустое сообщение
- **WHEN** пользователь пытается отправить пустое сообщение
- **THEN** сообщение не отправляется, поле ввода остаётся активным

### Requirement: Получение сообщений
Система ДОЛЖНА доставлять сообщения всем участникам комнаты в реальном времени.

#### Scenario: Получение нового сообщения
- **WHEN** один участник отправляет сообщение
- **THEN** все остальные участники видят сообщение в чате в течение 1 секунды

#### Scenario: Отображение отправителя
- **WHEN** сообщение получено
- **THEN** чат отображает идентификатор отправителя (имя сессии или "Аноним") и время отправки

### Requirement: История сообщений
Система ДОЛЖНА хранить историю сообщений для текущей сессии.

#### Scenario: Присоединение к существующему чату
- **WHEN** пользователь присоединяется к комнате, где уже есть сообщения
- **THEN** пользователь видит историю сообщений, отправленных до его прихода

#### Scenario: Очистка истории
- **WHEN** все участники покидают комнату
- **THEN** история сообщений удаляется вместе с комнатой

### Requirement: Форматирование сообщений
Система ДОЛЖНА обрабатывать текст сообщений.

#### Scenario: Обычный текст
- **WHEN** сообщение содержит обычный текст
- **THEN** текст отображается как есть

#### Scenario: Специальные символы
- **WHEN** сообщение содержит HTML или специальные символы
- **THEN** система экранирует HTML-теги для предотвращения XSS-атак

#### Scenario: Длина сообщения
- **WHEN** сообщение превышает 1000 символов
- **THEN** система обрезает сообщение до 1000 символов или показывает ошибку

### Requirement: Уведомления о новых сообщениях
Система ДОЛЖНА уведомлять пользователей о новых сообщениях.

#### Scenario: Новое сообщение при активном окне
- **WHEN** приходит новое сообщение и окно активно
- **THEN** чат прокручивается к новому сообщению

#### Scenario: Новое сообщение при неактивном окне
- **WHEN** приходит новое сообщение и окно неактивно
- **THEN** система может показать push-уведомление (если браузер поддерживает)

### Requirement: Индикатор набора текста
Система МОЖЕТ показывать, когда участник набирает сообщение.

#### Scenario: Начало набора
- **WHEN** пользователь начинает ввод текста в поле чата
- **THEN** остальные участники видят индикатор "[Имя] печатает..."

#### Scenario: Завершение набора
- **WHEN** пользователь перестал вводить текст (отправил сообщение или очистил поле)
- **THEN** индикатор "печатает" скрывается
