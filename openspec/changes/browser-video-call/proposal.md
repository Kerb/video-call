## Why

Существует потребность в простом решении для видеосвязи через браузер без установки дополнительного ПО. Текущие решения либо требуют регистрации, либо избыточно сложны для быстрых звонков между 2+ участниками. Это решение позволит пользователям мгновенно подключаться к видеовстречам через общий код комнаты.

## What Changes

- Добавляется возможность создания видеозвонков через браузер с использованием WebRTC
- Пользователи могут присоединиться к звонку по 6-значному коду комнаты (латинские буквы + цифры)
- Поддержка мобильных и десктопных браузеров (Chrome, Safari, Firefox, Edge)
- Анонимный доступ без регистрации — вход только по коду комнаты
- Автоматическое переподключение при случайном разрыве соединения
- Полный набор медиа-функций: видео, аудио, чат, демонстрация экрана, управление устройствами

## Capabilities

### New Capabilities

- `video-calls`: Базовая функциональность видеозвонков через WebRTC с поддержкой 2+ участников
- `room-management`: Управление комнатами — создание, вход по коду, генерация 6-значных кодов, восстановление сессии
- `media-controls`: Управление медиа-устройствами — камера, микрофон, демонстрация экрана, выбор устройств
- `chat`: Текстовый чат внутри комнаты для обмена сообщениями между участниками

## Impact

- **Фронтенд**: Vanilla JavaScript или минималистичный фреймворк (Vue.js/React), WebRTC API, MediaDevices API
- **Signaling-сервер**: Node.js + Socket.io для обмена SDP-описаниями и ICE-кандидатами
- **Браузеры**: Требуется поддержка WebRTC, getUserMedia, RTCPeerConnection
- **Сеть**: Требуется HTTPS для доступа к медиа-устройствам (кроме localhost)
- **Зависимости**: Socket.io client/server, возможно STUN/TURN серверы для обхода NAT
